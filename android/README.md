Open android/ in Android Studio. Set Config.BASE_URL to http://10.0.2.2:5000/ for emulator or your PC LAN IP for a real phone on same Wi-Fi. For production use HTTPS. Run on a real Android phone, grant location/notification permissions, enter vehicle ID and device secret from web registration, then tap Start visible tracking. The foreground notification stays visible; use Stop in app to end. This starter starts while app is visible; Android background location and foreground-service policy requirements must be reviewed before Play Store release.
